# MANIFEST 1.0
**See it. Believe it. Live it.**

Mobile-first goals, vision-board and manifestation web app, designed around iPhone 16 Pro.

## Brand
The MANIFEST mark uses opening red theatre curtains, an illuminated stage/path and a figure stepping forward: **Step into your story.**

## Run
Upload the files in this folder to the root of a GitHub repository and enable GitHub Pages, or deploy to any static host.

## Included
- MANIFEST branded splash and iPhone Home Screen icon
- Home dashboard
- Editable vision board
- Goal creation/editing/deletion
- Goal-to-vision linking
- Progress, target date, why, milestones, obstacle, If→Then plan and next action
- Six-step manifestation ritual: SEE → FEEL → AFFIRM → CONTRAST → PLAN → ACT
- Future Me / My Reality
- Manifestation history
- Persistent localStorage with migration from the earlier BECOMING build
- JSON data export
- Responsive iPhone-safe-area navigation
